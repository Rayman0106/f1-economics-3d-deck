# Preview provenance · Final J

The current gallery was captured on **12 November 2026** from the accepted J
development preview, using its native camera/actor samplers and default
`broadcast` material mode. The J source assembler matched the production build
before version-title promotion; this is current scene content, not the October film.

Nine stills cover the grid (opening 16.3 s), the on-track hero (24.4 s), cover,
budget, development and conclusion reading pages, competition (12.15 s), team
inspection (15 s) and an optional costs-transition frame (1.9 s). Per-image poses
and files are listed in [manifest.json](manifest.json).

Captures use the browser's existing viewport and physical pixel ratio. The WebGL
buffer was **960×540**. The full browser screenshots were **920×1256**, cropped to
the actual **920×518** presentation stage at `(0, 276)`. Header, diagnostic controls
and preparation reports are excluded. There was no viewport enlargement,
recolouring, model replacement or generated scene content.

The opening is sampled at **30 frames/s**, source time **16.0–31.0 s** inclusive,
451 browser frames. It begins at the red-light sequence, includes the launch,
overtakes and the complete handoff to the title slide. A one-second end hold is
appended. `F1-Economics-J-Opening.mp4` is **920×518 / 30 fps / 16.03 s**, silent.
The README GIF is **540×304 / 6 fps**, encoded from that clip for page loading.
This is a frame-sampled native animation export, not a live performance test or
an engine-audio demonstration.

Only stage cropping, image/video encoding and the final hold were applied.
Existing model, font, photo, texture and sound attribution remains applicable.
The media manifest includes current file integrity records.

The [October highlights](https://github.com/Rayman0106/f1-economics-3d-deck/releases/download/v2026.10.20/F1-Economics-Highlights.mp4)
are historical, 1080p60 excerpts from the 2026-10-13 recording; they are no longer
the primary current-version preview. The separate Showcase technical film and
Interactive Lab keep their previously published versions.

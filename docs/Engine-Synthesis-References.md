# Procedural engine sound references

Reviewed 2026-10-13 for the user's request to replace the rejected recorded-bank sound.

- [Antonio-R1/engine-sound-generator](https://github.com/Antonio-R1/engine-sound-generator): browser Web Audio / AudioWorklet engine acoustics. The bidirectional pressure-wave delay/reflection structure informed and is adapted in our Guide class. MIT copyright/license is preserved. We did not bundle its complete cylinder solver, Three.js wrapper or WASM runtime. Our simplified V6 firing/pulse, flow-noise, smoothing and multicar renderer is presentation-specific code.
- [DasEtwas/enginesound](https://github.com/DasEtwas/enginesound): synthetic engine audio with intake, engine vibration and exhaust chamber/pipe mixing. Design reference only.
- [ange-yaghi/engine-sim](https://github.com/ange-yaghi/engine-sim): full native combustion simulation and acoustic rendering. Design reference only; its full physics cost/build dependencies are not suitable for multiplying across 22 cars inside this existing offline presentation.
- [Baldan et al. (2015), Physically informed car engine sound synthesis for virtual and augmented environments](https://air.iuav.it/retrieve/de164c2a-5461-60ee-e053-3a05fe0a7787/SIVE15_submission_4.pdf): procedural combustion and acoustic waveguide approach.
- [MDN AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet) and [addModule](https://developer.mozilla.org/en-US/docs/Web/API/Worklet/addModule): audio-thread rendering. An embedded data module is used for file origins; browser previews use a local Blob module. Both omit credentials and require no runtime network resource.

Reviewed again 2026-10-14 after the user reported excessive electronic timbre, incorrect shift rhythm and `Sound unavailable` from the desktop shortcut.

- [OpenF1 API documentation](https://openf1.org/docs/): public speed, RPM, gear, throttle and brake fields, sampled at approximately 3.7 Hz. We examined the 2025 Monza qualifying session 9908, driver 1, lap 17 (78.792 seconds). Median observed RPM/(m/s) in loaded gears 2–8 was rounded to 344/277/220/188/163/144/128. The first-gear value is illustrative because the lap contained no first-gear run; only two loaded second-gear samples were present. This limited reference informs speed-linked gear states and nonuniform acceleration cadence. The sampling rate does not resolve exact shift transients, and these settings are not manufacturer gear ratios or a replica of private telemetry. No telemetry service is contacted at runtime. Raw reference and analysis are retained in the local maintenance record, not embedded into the presentation.
- [Mercedes W17 technical specification](https://www.mercedesamgf1.com/f1-w17-2026-technical-specifications): six-cylinder 1.6-litre engine, eight forward gears and sequential hydraulic selection. It supports the general configuration, not the sound tuning or private shift thresholds.
- [MDN createScriptProcessor](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/createScriptProcessor): deprecated API, used only as a bounded compatibility path when the preferred AudioWorklet cannot load or stops. The same embedded Mixer and Engine DSP is used in both paths; it does not restore recordings, fetch an external module, change browser security or require a server.

The 2026-10-14 tuning damps high frequencies inside the pipes and at the outlet, and adds small per-combustion timing/amplitude variation with colored, combustion-driven flow noise. There is still no sustained electric oscillator. Upshifts use the evolving road speed, per-gear thresholds and a brief torque transient. Higher gears naturally last longer as acceleration decreases. Downshifts use a separate short cadence only during actual braking. Camera reveals, cruising and photographic freezes remain free of catch-up shifts.

Verification limitation: the native browser inspection tool stopped because it could not determine the current Edge URL. The file-origin data-module path and forced Worklet failures were exercised in code-level integration tests, including real PCM output, the `Sound on` control, all 22 independent voices and a quiet stop. Direct playback of the final file in desktop Edge was not inspected this revision.

The result is an illustrative exterior racing-engine timbre, not a validated thermodynamic V6 simulation or an exact current F1 engine recording. Each physical car keeps its own sound state. The prior engine recordings are preserved as original inputs and unused assets, not played by this renderer.
